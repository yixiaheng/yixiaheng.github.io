## 项目介绍

这是项目页面的示例，也是正在搭建的博客本身。后续可替换为自己的游戏、工具或其他作品。

## 主要功能

- Markdown 写作与站内搜索。
- 分类、标签和文章归档。
- 独立项目介绍与关联随笔。
- GitHub Pages 托管与自动发布。

## 下载与源码

本项目暂未提供成品下载。其他项目可以按需配置 GitHub 源码地址及 Releases 下载链接；闭源项目可以只放成品下载。
